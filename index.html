matrixxx - ein D.I.Y Linux Live System

matrixxx ist zunächst eine Sammlung von bash Skripten, mit deren Hilfe man sich sein eigenes Linux Live System erzeugen kann. (Zumindest erzeuge ich damit mein eigenes System - und diese Möglichkeit möchte ich in diesem Zuge der Allgemeinheit zur Verfügung stellen). Hiermit lassen sich

  • ein für diese Zwecke angepasster moderner Kernel erzeugen
  • ein einfaches von USB Flash Laufwerken startbares Boot System aufbauen
  • und ein auf Debian basiertes modulares Betriebssystem zusammenstellen

Aus einem Build Lauf entsteht daraus ein System, welches direkt von einem USB Flash Laufwerk produktiv genutzt werden kann, ohne dieses zuvor installiert haben zu müssen. Ein System also für die Hosentasche, dass auf verschiedenster x86-Hardware in gleicher gewohnter Art und Weise nutzbar und bedienbar ist (soweit diese USB Flash Laufwerke als Bootmedium zulässt).
